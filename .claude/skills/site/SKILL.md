# Livre du site

Site de Nicolas Leveugle, photographe indépendant à Ath (Hainaut, Belgique) : mariages, couples, portraits, événements, et photos pour commerces. Site statique (HTML/CSS/JS sans framework) sur GitHub Pages, domaine `nicolasleveugle.be`, branche `main` = en ligne. Nicolas n'est pas développeur : on lui répond toujours **en français simple**, sans jargon, en disant exactement où cliquer.
