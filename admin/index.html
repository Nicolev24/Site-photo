Connexion

Colle ton token d'accès personnel GitHub pour modifier le contenu du site.

Comment obtenir ce token ?
  1. Va sur github.com/settings/personal-access-tokens/new
  2. Repository access → "Only select repositories" → choisis Nicolev24/Site-photo
  3. Permissions → "Repository permissions" → Contents → "Read and write"
  4. Clique Generate token, copie-le (il ne sera affiché qu'une fois) et colle-le ci-dessus

Le token reste uniquement dans ton navigateur, il n'est jamais envoyé ailleurs qu'à GitHub. Tu peux le révoquer à tout moment depuis cette même page GitHub.
