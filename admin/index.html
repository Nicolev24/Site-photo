Configuration

Aucun mot de passe n'est encore configuré. Colle ton token GitHub une dernière fois pour en choisir un — ensuite, ce token ne te sera plus nécessaire au quotidien.

Comment obtenir ce token ?
  1. Va sur github.com/settings/personal-access-tokens/new
  2. Repository access → "Only select repositories" → choisis Nicolev24/Site-photo
  3. Permissions → "Repository permissions" → Contents → "Read and write"
  4. Clique Generate token, copie-le (il ne sera affiché qu'une fois) et colle-le ci-dessus

Ce mot de passe protège l'accès à l'administration du site : choisis-en un que toi seul connais, pas trop court (par exemple 4-5 mots, ou 12 caractères variés), et jamais utilisé ailleurs.
